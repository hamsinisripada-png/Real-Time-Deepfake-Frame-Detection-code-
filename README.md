# 🎭 Real-Time Deepfake Frame Detection

A real-time deepfake detection system that analyzes video frames using Computer Vision and Deep Learning techniques to identify manipulated facial content.

## 🚀 Features

- Real-time frame extraction
- Face detection using OpenCV
- Deepfake classification
- Confidence score visualization
- Webcam and video file support
- Lightweight and scalable architecture

## 🛠️ Tech Stack

- Python
- OpenCV
- TensorFlow / Keras
- NumPy
- Deep Learning
- Computer Vision
